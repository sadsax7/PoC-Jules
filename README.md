# PoC — Billetera Virtual + Agent as a Service (Inicio: Jules)

## Alcance (PoC)
Esta PoC valida un **slice mínimo** de producto (Identidad & Acceso) con calidad profesional:
- Frontend: Landing, Registro, Login + MFA simulado, Dashboard + Logout
- Backend: Registro, Login + MFA simulado, JWT, `/users/me`, MongoDB
- DevEx: CI, lint/format, pruebas AAA, documentación (OpenAPI + guías)

> Fuera de alcance PoC: saldo real, P2P, pagos, recargas, notificaciones, admin.
