# Frontend (PoC Wallet)

## Stack
- Next.js (App Router)
- TypeScript strict
- Tailwind CSS
- ESLint + Prettier

## Setup
```bash
npm install
npm run dev
```

Abrir: http://localhost:3000

## Styleguide
Ruta: `/styleguide`

Incluye:
- Paleta institucional (primary, bg-dark, text-light)
- Tipografia Inter
- Botones y estados base

## Tokens de color
- `primary`: #FF6B00
- `bg-dark`: #000000
- `text-light`: #FFFFFF

## Scripts
- `npm run dev`
- `npm run build`
- `npm run start`
- `npm run lint`

## Estructura
- `src/components/atoms`
- `src/components/molecules`
- `src/components/organisms`
- `src/components/templates`
